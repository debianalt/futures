# Sociotechnical Futures and Material Realities — Replication Materials

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18967219.svg)](https://doi.org/10.5281/zenodo.18967219)

Data and code for the research project *Sociotechnical futures and material realities: technology, dematerialisation, and the politics of evidence*.

## Repository structure

```
├── data/
│   ├── works.csv               # 4,465 deduplicated records from OpenAlex
│   ├── authorships.csv         # Author–institution–country links
│   ├── citation_edges.csv      # Intra-database citation network
│   ├── work_keywords.csv       # Author keywords
│   ├── work_topics.csv         # OpenAlex topic classifications
│   ├── search_provenance.csv   # Which query found each work
│   ├── shortlist.csv           # Top 150 ranked candidates (output of 01_study_selection.R)
│   ├── coding.csv              # Screening and coding of all 4,465 records
│   └── additional_records.csv  # Corpus studies identified via citation search
├── docs/
│   └── search_protocol.md      # Search documentation (queries, funnel, criteria)
├── R/
│   ├── 01_study_selection.R    # Scoring pipeline → shortlist
│   ├── 02_field_mapping.R      # Epistemic geography, disciplines, trends
│   └── 03_figure.R             # Fig. 2: competing sociotechnical futures
├── sql/
│   ├── schema.sql              # PostgreSQL schema (alternative to CSV)
│   └── queries.sql             # Analytical queries
├── figures/
│   ├── fig01_review_funnel.{jpg,png,pdf}      # Fig. 1: identification and inclusion flow
│   └── fig02_competing_futures.{jpg,png,pdf}  # Fig. 2: competing sociotechnical futures
├── corpus_report.py            # Funnel and corpus counts (single source of truth)
├── LICENSE                     # MIT
└── README.md
```

## Reproducing the counts reported in the manuscript

```bash
python corpus_report.py
```

Every count in the manuscript's methods section, Table 1, and the supplementary information is generated by this script from `data/coding.csv` and `data/additional_records.csv`.

## Reproducing the analysis

R ≥ 4.1 with `readr`, `dplyr`, `stringr`, `tidyr`, `forcats`, `ggplot2`, `here`:

```bash
Rscript R/01_study_selection.R   # score and rank → data/shortlist.csv
Rscript R/02_field_mapping.R     # field mapping (console output)
Rscript R/03_figure.R            # Fig. 2
```

## Data sources

- **Literature database**: Built from the [OpenAlex](https://openalex.org/) API via structured queries and citation snowballing from 9 seed papers. See `docs/search_protocol.md` for the full search strategy.
- **Figures**: Fig. 1 is generated from the funnel counts; Fig. 2 is a schematic diagram (no external data required).
